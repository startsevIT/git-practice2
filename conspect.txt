git init

git add <file> - добавление файла
git add <file> <file> <file> - добавление файлов
git add . - добавление всех файлов

Конвенция
git commit -m "[приставка]: сообщение" - добавление коммита с сообщением

feat: - приставка для обозначения нового функционала
fix: - приставка для обозначения исправлений ошибок
docs: - приставка для обозначения изменений в документации
refactor: - приставка для обозначения изменения внутренней структуры программного кода без изменения его поведения
